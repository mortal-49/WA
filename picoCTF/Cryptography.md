## RSA弱破解
### 原理  
  这玩意主要是定一个总位数（比如1024），然后随机生成两个各占总位数一半的大素数p,q（各512），两个素数相乘得到模数N，  
e为自己定义，常用指数为65537，这两个N,e为公钥指数。  
  私钥指数d，是e在模φ(N)下的逆元，逆元是啥嘞，俺也不懂，是这么算的：  
d = inverse(e, (p-1)*(q-1))  
e, (p-1)*(q-1)是两个互质的整数，最大公约数为1  
而能找到一个整数x，(a * x) % m = 1，这个x就叫做 a 在 模 m 下的逆元，记作 a⁻¹ mod m  
这个x就是d啦。
  
    
原则上，RSA以现在的技术不可破解，但是掌握原则的人犯傻了原则就没了  
在随机生成两个素数的生成器犯傻生成一个小素数那就完蛋啦，可以通过  
多个模数N,两两配对gcd找最大公因数，理论上素数太大计算时间超过你的寿命  
但是现在是理论在你这，找出来个2  
反推出私钥d，解密！

from sys import exit#导入exit函数，用于程序安全退出  
from Crypto.Util.number import bytes_to_long, inverse  
#导入两个核心函数  
#bytes_to_long字节串转换为大整数（RSA加密需要处理整数）    
#inverse计算模逆元（生成RSA私钥d）  
from setup import get_primes  
#生成指定位数的素数，素数只有1和自身两个因数  
  
e = 65537#公钥常用指数  
  
def gen_key(k):#生成指定总位数的RSA秘钥对，k:秘钥位数  
    """  
    Generates RSA key with k bits  
    """  
    p,q = get_primes(k//2)#生成两个素数，各占总位数的一半  
    N = p*q#计算模数N  
    d = inverse(e, (p-1)*(q-1))  
	#计算私钥指数d，d是e在模φ(N)下的逆元，其中φ(N)=(p-1)*(q-1)（欧拉函数）  
	#inverse(a, m)等价于求解 ax ≡ 1 (mod m)，这里求的是e*d ≡ 1 (mod (p-1)*(q-1))  
	#模逆元：e, (p-1)*(q-1)是两个互质的整数，最大公约数为1  
	#        能找到一个整数x，(a * x) % m = 1，这个x就叫做 a 在 模 m 下的逆元，记作 a⁻¹ mod m  
  
    return ((N,e), d)#返回公钥和私钥  
  
def encrypt(pubkey, m):#加密  
    N,e = pubkey#解包公钥  
    return pow(bytes_to_long(m.encode('utf-8')), e, N)#转换为utf-8编码格式，再转换为大整数，pow加密  

def main(flag):
    pubkey, _privkey = gen_key(1024)
    encrypted = encrypt(pubkey, flag) 
    return (pubkey[0], encrypted)

if __name__ == "__main__":
    flag = open('flag.txt', 'r').read()
    flag = flag.strip()
    N, cypher  = main(flag)
    print("N:", N)
    print("e:", e)
    print("cyphertext:", cypher)
    exit()
